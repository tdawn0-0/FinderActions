## Intent and current state

FinderActions is an offline Finder script launcher; keep its small AppKit Host, on-demand SwiftUI Settings, and thin FinderSync. No accounts or telemetry. Production transport remains distributed notifications; do not claim authentication. Follow existing grouped Forms, @Observable state, Result validation, Swift Testing tests with temporary filesystem fixtures and isolated preferences.

Current verified excerpts at baseline:
- ActionInspectorView.runLiveTest: `executor.execute(action: currentAction, paths: [homePath], containerPath: homePath)`. Testing uses only home and is real execution.
- ActionInspectorView.displaySection exposes ShowWhen/group/symbol, while ShowWhenMatcher.matchesExtRules already matches `context.paths.allSatisfy` against path extensions.
- AppState.addNewAction creates enabled always-visible shell actions with an echo stub. ActionExecutor.runShell prioritizes a nonempty scriptFile over scriptInline.
- Onboarding Skip/Finish both call completeOnboarding. PermissionsSettingsView uses substring Registered to claim readiness, even when enablement is unknown.
- IPCServer.finish writes completion logs and notifications using actionId; no active execution state. General settings have one notificationsEnabled Boolean.
- ManifestStore persists JSON metadata separately from scripts; Actions toolbar lacks import/export.
